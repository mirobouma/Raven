************
Raven
************

Raven is a small game engine focussing on multi-threaded performance.

- Requirements:
	* "Visual Studio 2017" (with CMake tools installed).
	* "make" to build Sphynx documentation (GnuWin32-make on windows).

- To build documentation using Sphinx:
	* "Python" to build Sphynx documentation.
	* "Sphinx" python package installed (use pip install sphinx)
	* "Breathe" python package installed (use pip install breathe)

To build Raven, simply open the folder in Visual Studio 2017 and select CMake -> Build All.
